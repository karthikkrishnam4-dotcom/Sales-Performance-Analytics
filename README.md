# Sales Performance & Business Analytics

## Project Overview

This project analyzes sales data using Python and SQL to understand sales performance, profitability, customer behavior, product performance, and regional trends.

## Dataset

The project uses the Superstore sales dataset containing information about:

- Orders
- Customers
- Products
- Categories
- Regions
- Sales
- Profit
- Quantity
- Discount
- Shipping methods

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- SQLite
- Jupyter Notebook

## Analysis Performed

### Python Analysis

- Data cleaning and exploration
- Sales and profit analysis
- Category analysis
- Regional analysis
- Monthly sales trends
- Top products and customers
- Sales vs profit analysis
- Discount vs profit analysis

### SQL Analysis

- Total sales and profit
- Sales and profit by category
- Regional performance
- Monthly and yearly sales
- Top products and customers
- Loss-making products and sub-categories
- Profit margin analysis
- Customer segment analysis
- Shipping mode analysis
- State and city performance

## Visualizations

The project includes visualizations for:

- Yearly sales trends
- Yearly order trends
- Yearly profit trends
- Profit margin trends
- Category performance
- Regional performance
- Product performance
- Customer performance
- Discount vs profit
- State and sub-category performance

## Key Insights

The analysis helps identify high-performing categories, regions, products, and customers while also highlighting loss-making areas and the relationship between discounts and profitability.
